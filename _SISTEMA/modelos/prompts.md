# Pedidos prontos para o Claude Code / Codex

## Marca
```text
Configura minha marca. Joguei logo e foto em 0-MARCA/assets.
```

## Reel falando pra câmera
```text
Edita o vídeo <arquivo> de 1-MATERIAIS-PARA-EDITAR no estilo split explicativo.
Usa os elementos do ELEMENTOS.md (ou sugere). Me mostra o plano de cortes antes.
```

## Só a voz
```text
Faz um vídeo minimalista pontilhado com o áudio <arquivo>. Mostra o moodboard antes de animar.
Entrega com e sem trilha.
```

## Aula
```text
Edita a <arquivo> no estilo aula com moldura. Etiqueta: "Aula 02 · <título>".
```

## Elementos específicos
```text
No projeto <slug>, usa LEG-02 na legenda, TRA-05 nas viradas e fecha com FEC-12.
```

## Revisão
```text
Revisa o projeto <slug> com a ficha de revisão e me manda o rascunho.
```

## Entrega
```text
Aprovado. Renderiza em 4K a −14 LUFS e coloca em 3-EDITADOS.
```
