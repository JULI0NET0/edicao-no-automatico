# Mapa de tokens

Os exemplos das skills foram feitos na marca do Julio Neto. Cada valor do exemplo corresponde a um papel do manual. Ao adaptar um exemplo, troque pelo valor do papel no `0-MARCA/MANUAL-DA-MARCA.md`.

| Valor no exemplo | Papel no manual | Uso |
|---|---|---|
| `#0A0A0A`, `#050505`, `#111111` | `cores.fundo` | fundos, palcos, base dos degradês |
| `#1C1C1C` | `cores.superficie` | cards, painéis, fim do degradê |
| `#F97316`, `#EA580C`, `#FDBA74` | `cores.acento` | palavra ativa, destaque, botão, linha protagonista (o escuro/claro viram variações do acento) |
| `#FFFFFF` | `cores.texto` | títulos, legenda |
| `#A8A8A8` | `cores.texto-secundario` | labels, @handle, linhas secundárias |
| `#282828`, `#3A3A3A` | `cores.borda` | bordas, divisórias, barras neutras |
| `League Gothic` | `fontes.titulo` | títulos de impacto |
| `Montserrat` | `fontes.corpo` | legenda, labels |
| `Playfair Display`, `EB Garamond` | `fontes.destaque` | palavra-chave em itálico |
| `{{HANDLE}}`, `@juli0net0` | `handle` | end card, assinatura |
| `{{NOME}}`, `Julio Neto`, `Júlio Neto` | `nome` | end card, lower third |
| `avatar-julio.jpg` | `avatar` | card de seguir |

Regras que continuam valendo com qualquer marca:
- O acento aparece em **uma coisa por vez** (o que deve ganhar o olho).
- Acento sobre acento não lê: palavra de ênfase sobre fundo de acento vira contorno.
- Gráficos com dado fictício levam a tag "ILUSTRATIVO".
